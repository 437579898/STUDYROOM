模型设置

接 入 方 式

DeepSeek 官方为 https://api.deepseek.com/v1；其它中转站填它给你的地址，末尾要带 /v1。
常用：deepseek-chat（快）、deepseek-reasoner（会先思考再回答）。
只粘贴 sk- 开头的那一串，不要把「API Key：」这样的前缀一起复制进来（中文冒号会导致请求失败）。
密钥保存在本机服务端 data/config.json，不会写进浏览器缓存，也不会随页面发送到别处。
讲题建议 0.4 ~ 0.7，太低会显得死板，太高容易跑偏。

访 问 与 版 面

设了之后，同一局域网的其他设备（平板 / 手机）第一次打开要输入它。
不设的话，同一个 WiFi 下任何人都能打开，并且能用掉你的 API 额度。至少 4 位。
○ 未设口令
固定版面：整站按 1200 × 760 的版面等比缩放到窗口里，窗口拉大拉小、浏览器缩放、换设备，版面比例都不变。
自适应：栏宽随窗口伸缩，很窄的窗口会自动收起侧栏。

本 机 数 据

纯网页模式下，学习记录存在这台设备的浏览器里，换设备或清理浏览器数据就会丢。 导出成文件可以备份，也可以搬到另一台设备上继续（API Key 不会写进存档，换设备要重新填一次）。
